## 1. 技术底盘与约束（所有改动都必须守住）

1. 纯静态、无构建、无外部 CDN。GitHub Pages 直接跑，双击本地文件也能跑。
2. 文件结构升级为：
   ```
   index.html          UI 骨架 + 样式
   src/data.js         静态数据表（角色/类型/受众/设施/对手…）
   src/events.js       事件库（最大的一块，独立文件）
   src/art.js          美术清单 manifest + 取图函数
   src/game.js         逻辑与渲染
   assets/scene/*.webp
   assets/portrait/*.webp
   ```
   用多个 `<script>` 顺序加载，不用模块化（保持 file:// 可跑）。
3. 存档 `VERSION` 升到 2，`normalize()` 负责补齐所有新字段默认值。**老存档必须能继续玩**，测试里加一条 v1 档迁移用例。
4. 性能预算：首屏 JS < 200KB；图片全部 `loading="lazy" decoding="async"`；资源总量 ≤ 4MB。
5. **无图可玩**：每个图位都有 CSS 降级样式，`onerror` 时退回现在的纯 CSS 表现。图没出完也能随时 push。
6. 移动端优先，现有 760px / 1100px 断点不动，新 UI 一律先按 390px 宽验。
7. 代码风格：数据表写成可读的多行对象（事件要人看的），逻辑函数保持现有紧凑风格。

## 2. 场景图规范

### 2.1 画风锚（所有图共用，不许一张一个风格）

- 数字厚涂概念美术（不是照片、不是像素、不是二次元）
- 低饱和暖调：单一钨丝灯/工作灯主光 + 冷色窗光或显示器冷光做对比
- 轻胶片颗粒，暗部偏棕黑，和 UI 的 `#171311 / #9f2f2a / #c99845 / #f7f2e9` 咬合
- **画面内不出现任何文字**（中英文都不要，避免生成式乱码）。需要文字一律由代码叠加——沿用你 `合成海报.py` 那套做法
- 人物一律中远景、侧影或背影，**不出现清晰面孔**（脸交给立绘，也避免 AI 崩脸）
- 构图上方 1/3 留暗部，用来压标题

人物只用中远景或背影，不出现清晰面孔；横构图 16:9。

[负面] 不要文字/水印/logo，不要漫画或像素风，不要高饱和霓虹，

## 3. 人物立绘规范

难点：主创是程序随机生成的（30 个名字池 × 8 个岗位 × 特质 × 明星），不可能一人一图。

### 3.1 方案：按岗位分桶的肖像库 + 存档固化

- 每个岗位备 N 张半身像，人物创建时随机领一张，把 `face` 存进存档 → **同一个人这一局永远同一张脸**
- 明星（★）单独一套更华丽的（红毯布光、杂志封面感），和普通人一眼能分出来
- 换算量：
  - MVP：8 岗位 × 2 张 + 明星 4 张 = **20 张**
  - 完整：8 岗位 × 3 张 + 明星 6 张 = 30 张
- 规格：**512×640 WebP，q=80，≤70KB**。不要透明底（生成不稳），用纯深色渐变底，前端拿 CSS 圆角+内阴影收口

### 3.2 立绘 prompt 模板

```
[前缀] 半身人物立绘，中国当代影视从业者，数字厚涂写实插画，
3/4 侧身、视线看向镜头，中性表情不做夸张，柔和三点布光偏暖，
背景为单一深色渐变、无任何环境细节，肩胸以下裁切，人物居中留边，竖构图 4:5。

[主体] ← 岗位 + 年龄段 + 着装，见下表

[负面] 不要文字/logo，不要动漫或赛璐璐画风，不要过度磨皮美颜，
不要夸张表情，不要背景环境，不要多人。
```

| 岗位 | 着装与道具提示（各出 2–3 张，年龄段错开） |
|---|---|
| 制片人 producer | 40 上下，深色夹克或衬衫挽袖，挂着工作证，手里拿排期表 |
| 导演 director | 35–50，工装外套或马甲，脖子上挂监视器耳机，戴帽子 |
| 编剧 writer | 30 上下，针织衫或衬衫，抱着笔记本电脑，略疲惫 |
| 演员 actor | 25–35，气质突出，妆面干净，戏服或简约常服各一版 |
| 摄影指导 camera | 40 上下，多口袋背心，肩上搭着摄影机背带，手上有测光表 |
| 剪辑师 editor | 30 上下，卫衣或格纹衬衫，戴监听耳机，冷光打在半边脸 |
| 美术指导 art | 30–45，围裙或沾颜料的衬衫，手里拿色卡和图纸 |
| 宣发经理 marketing | 30 上下，职业装，拿着手机和物料样张 |
| ★ 明星 | 4–6 张，红毯闪光灯侧逆光、高对比、服装更强造型感，气场要压得住 |

命名：`assets/portrait/<role>-01.webp`、`star-01.webp`。加图只要在 `ART.portrait` 里补一行，逻辑不动。

### 3.3 用在哪

1. 主创列表行：44px 圆形缩略（替换现在的彩色圆点）
2. 主创档案弹窗：240px 大图，配五维条
3. 片场总览 `crew-dots`：换成小头像队列，一眼看出剧组阵容
4. 组队勾选、招募名单、塌房事件、挖角对手：全部带脸
5. 作品报告：列出主创阵容小头像（"这部片是谁拍的"）

### 3.4 存档兼容

`person()` 生成时写 `e.face`；`normalize()` 里给老存档的每个 staff 按 role 补发一张。

## 4. 事件系统规范

目标：从 19 条扩到 **130+ 条**，并且让事件之间有因果、有条件，而不是纯随机弹窗。

### 4.1 统一数据结构

```js
{
  id:'shoot_rain',          // 唯一，用于冷却/去重/存档记录
  tier:'project',           // project | company | person | release | saga | season
  phase:2,                  // tier=project 时限定阶段，null=全阶段
  mood:'rain',              // 取哪张氛围图
  weight:10,                // 轮盘权重
  once:false,               // 一局只触发一次
  cooldown:24,              // 单位：周
  cond:c=>c.p.scale!=='web' && c.S.money>200000,
  title:'雨戏等不到雨',
  text:c=>`《${c.p.name}》外景组连等四天，天气预报还是晴。`,
  choices:[
    {label:'改夜戏', cost:0, note:'导演 +5', apply:c=>{...}},
    {label:'调洒水车来', cost:160000, note:'视听 +8', apply:c=>{...}, chain:'water_bill'}
  ],
  onSkip:c=>{...}
}
```
`c`（上下文）= `{S, p:项目, e:人物, w:作品}`，按 tier 填。

### 4.2 六类事件与配额

| tier | 说明 | 目标条数 |
|---|---|---|
| `project` | 片场事件，绑定制作阶段（现有 15 条归入） | 45 |
| `company` | 不绑项目：税务稽查、平台采购政策变化、投资人来访、员工集体要求涨薪、设备被盗、办公室漏水、同行挖人 | 25 |
| `person` | 绑定某个主创：瓶颈期、师徒、绯闻、想当导演、要求演主角、家里出事要请假、被对手约饭 | 20 |
| `release` | 上映期：盗版流出、影评人长文、短视频二创爆红、路演翻车、同档期对手撤档、口碑逆转 | 20 |
| `saga` | 多幕连锁（现有 censor/placement/injury 升级），每条 2–4 幕、跨月、幕间有分支 | 8 条 / 约 25 幕 |
| `season` | 日历节点：春节档备战、暑期档、电影节报名、年会、金幕奖（已有） | 6 |

### 4.3 调度规则

- **每周最多弹 1 个窗**。优先级：`saga > release > project > company > person`
- 抽取顺序：过滤 `cond` → 过滤冷却（`S.evtLog[id]` 记录触发周）→ 过滤 `once` → 按 `weight` 轮盘
- 近 10 条内不重复
- **无选择的氛围事件走新闻流不弹窗**：单独一个 `flavor` 池（约 40 条行业新闻、对手动态、市场传闻），让右侧消息栏有信息量而不打断节奏
- 4 倍速时，弹窗自动暂停推进（现有 `pauseForModal` 已经是这个逻辑，保留）

### 4.4 文案规范（这条最重要）

- **每条事件必须有一个具体细节**：人名、数字、地名、时间。"主演档期冲突"是废话，"男主只剩 11 天档期，第 12 天要进另一个组"才是事件
- 不写总结句、不写升华句。事件末尾不许出现"这是一次考验/如何抉择，就看你了"
- 选项是人话动词短语："改夜戏"、"洒水车拉过来"、"给他加两个点"，不是"选择方案 A：调整拍摄计划"
- 后果提示只给数值向（`视听 +8`），不煽情
- 新闻条 ≤ 45 字
- 用行业实词：通告、棚期、盒饭、过审、备案、龙标、密钥、点映、路演、二创、排片率、上座率、分账比

## 5. 机制规范

现在最大的问题不是机制少，是**推进期玩家没事干**——按 4 倍速看进度条走完，中间只有一两个弹窗。以下按性价比排序，前四项是主轴。

### M1 周指令（解决"没事干"，最高优先）
每个在制项目每周可下 **1 条指令**，免费，不下也行：

| 指令 | 效果 |
|---|---|
| 赶进度 | 进度 +15%，本周质量收益 -30%，全组体力 -3 |
| 抓质量 | 本周质量 +25%，进度 -20% |
| 安抚剧组 | 体力 +6，默契积累 +1 |
| 压成本 | 本周人力支出 -30%，质量 -15%，体力 -2 |
| 不干预 | 小概率触发正面事件（灵感、意外好镜头） |

UI：项目卡上一排 5 个小按钮，选中高亮，推进一周后清空重选。连续 3 周赶进度会触发"剧组怨气"事件。

### M2 档期与排片（把发行从"选个月份"变成博弈）
- **档期热度表**：春节档（1–2 月）×1.45、暑期档（7–8 月）×1.3、国庆档（10 月）×1.2、贺岁（12 月）×1.15，其余 ×1.0。大档期同时竞争密度翻倍
- 可选档期从 3 个月扩到 **6 个月**（等得越久越能避开对手，但成片压着不回款、宣发要重启）
- 定档后可 **改档一次**，赔付已投入的 8%
- 院线上映改成 **5 周曲线**：首周 = 质量 × 宣发 × 排片率；第 2 周跌幅由口碑决定（评分 >7.5 走长线，<6 断崖 -65%）；显示排片率和上座率
- 对手会"贴档"：你定了大档期，实力高的对手有概率跟进同档

### M3 合约与人员流动（让"人"有变数）
- 每人 `contract{until, salary, share}`，1–3 年
- 到期前 3 个月提示续约：涨薪幅度按等级/明星/近期作品评分算；可用"参与分红"压低当期现金支出
- 谈崩 → 离开公司，且大概率被对手签走（会在新闻里看到他给对手拍片）
- 明星可选**片酬制**（不发月薪，单项目一次性付），缓解月度现金流
- 对手挖角不再只是你挖别人，别人也会来挖你（默契高、评分高的人最容易被盯上）

### M4 舆情值（公司的"路人缘"）
- `S.buzz` 0–100，初始 50
- 影响：首周表现 ±15%、招募签约金 ∓20%、部分事件权重
- 加分：高分作品、获奖、正面公关、二创爆红
- 扣分：塌房、连续烂片、植入争议、拖欠工资
- 战略页给一条 SVG 折线（近 52 周），不做花哨图表

### 备选（第二轮再看，不进第一期）
- **M5 融资**：天使/平台预付/银行贷款，带利息与还款期，解决前期资金死锁

## 6. 乐趣层规范

数值做完了，缺的是"这一局讲出了一个什么故事"。

1. **开局背景 4 选 1**（重玩性）
   - 电视台出走：起始 620 万、团队齐，但声望 0
   - 电影节新贵：起始资金少一半，声望 +12，核心影迷基本盘大
   - 富二代接盘：起始 1500 万，但每年被家里抽走 200 万，且必须两年内出一部盈利片
   - 草台班子：起始 200 万、3 个人，前两部只能做网络电影
2. **五种结局**（按路线判定，不只看估值）：行业巨头 / 作者厂牌 / 平台代工厂 / 被收购退场 / 资金链断裂
3. **公司编年史**：每部作品自动写一行（年份+片名+评分+一句事件），结局时输出完整传记，可一键复制
4. **程序化海报**：片名 + 类型色板 + 评分自动生成 SVG 海报，片库变成收藏册（纯代码，不占图片预算）
5. **首映夜仪式感**：评分逐位滚动揭晓、票房日报以 toast 形式逐周播报、获奖时全屏金色过场
6. **复盘**：作品报告加一句"如果当初…"——指出这部片最拖后腿的那一项（档期撞车 / 表演不足 / 宣发太省）
7. **名人堂**：一局结束后，把最出色的 3 名主创写进独立的 localStorage 键，下一局有概率作为候选人出现

## 7. 施工流程

每期都可独立发布、可回滚，做完就 push 到 Pages。

| 期 | 内容 | 验收 |
|---|---|---|
| **P0 地基**（半天） | 拆 `src/data.js`/`events.js`/`art.js`/`game.js`；`VERSION=2` + 迁移；旧单文件移进 `legacy/`；测试补 v1 迁移用例 | 老存档能继续玩，行为与现在完全一致 |
| **P1 美术骨架 + 出图清单**（半天） | 图位、`.no-art` 降级、`face` 字段、`ART` manifest 全部就位；**同时把第 2、3 章清单交给你去出图** | 一张图都没有时，游戏表现和现在一样；丢进一张图就多一处变好看 |
| **P2 事件系统**（1–2 天） | 调度器 + saga 引擎 + flavor 新闻池；第一批 60 条事件 | 一局 10 年不重样；每周最多一个弹窗 |
