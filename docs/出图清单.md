给 GPT 用的完整 prompt，一张一块，复制整段即可。**文件名必须完全一致**（大小写、连字符），
丢进对应目录游戏就会自动用上，不需要改代码。

- 场景图 → `assets/scene/`，**1280×720，导出 WebP，质量 78，单张 ≤90KB**
- 氛围图 → `assets/scene/`，960×540 也可以（会被拉伸裁切），≤60KB
- 立绘 → `assets/portrait/`，**512×640，WebP，质量 80，≤70KB**
- GPT 出的是 PNG，转换命令（Mac 装了 webp 工具的话）：`cwebp -q 78 in.png -o out.webp`；
  没装就 `brew install webp`。转不了也可以先直接把 PNG 改名成 `.webp` 丢进去应急（浏览器认内容不认后缀），但体积会大。
