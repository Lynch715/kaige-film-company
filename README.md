# 开个影视公司

一款可直接在浏览器游玩的影视公司经营模拟游戏。

从旧摄影棚和五人主创团队起步，管理多条制作管线、打造IP与续作、谈判发行报价并争夺档期，在五类观众和六家竞争公司构成的市场中建立自己的影视版图。

## 在线游玩

https://lynch715.github.io/kaige-film-company/

## 主要玩法

- 1/2/3 条随公司等级开放的并行制作管线
- 原创IP、正统续集、衍生作品与重启开发
- 三方发行报价、未来三个月定档与同期竞争压力
- 追加宣传、海外版权、导演剪辑版等发行后运营
- 五类观众资产与六家会真实排片、发行和成长的竞争公司
- 剧本市场与市场风向
- 主创招聘、体力和能力成长
- 剧本开发、前期筹备、正式拍摄、后期制作
- 片场随机事件与制作选择
- ★ 明星主创：稀有明星候选人，票房号召力/奖项体质/话题体质/戏路百变四种专属特质
- 搭档默契：老搭档合作两部以上形成评分加成
- 连锁事件：敏感题材、广告植入、带伤硬拍等抉择会在数周后带来后续危机
- 明星塌房危机：公关、切割还是硬刚，三种应对三种后果
- 对手互动：挖角对手主创、抢签限时王牌剧本、50 万票房对赌
- 七阶经营目标（达成有现金/名气/声望奖励）与十项成就墙
- 院线、流媒体买断、网络分账三种差异化发行方式
- 作品回款、奖项、设施升级与十年公司评价

游戏为纯静态单页应用，支持本机存档和手机浏览器游玩。
