# 开个影视公司

一款可直接在浏览器游玩的影视公司经营模拟游戏。

从旧摄影棚和五人主创团队起步，挑选剧本、组织拍摄、完成后期，通过院线、流媒体买断或网络分账发行作品，并逐步建设自己的影视基地。

## 在线游玩

https://lynch715.github.io/kaige-film-company/

## 主要玩法

- 剧本市场与市场风向
- 主创招聘、体力和能力成长
- 剧本开发、前期筹备、正式拍摄、后期制作
- 片场随机事件与制作选择
- 院线、流媒体买断、网络分账三种发行方式
- 作品回款、奖项、设施升级与十年公司评价

游戏为纯静态单页应用，支持本机存档和手机浏览器游玩。
