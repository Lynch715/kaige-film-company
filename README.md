# 开个影视公司

一款可直接在浏览器游玩的影视公司经营模拟游戏。

从旧摄影棚和五人主创团队起步，管理多条制作管线、打造IP与续作、谈判发行报价并争夺档期，在五类观众和六家竞争公司构成的市场中建立自己的影视版图。

## 在线游玩

https://lynch715.github.io/kaige-film-company/

## 主要玩法

- 四种开局：电视台出走 / 电影节新贵 / 家里出钱（年抽成＋两年之约）/ 草台班子（前两部限网络电影）
- 1/2/3 条随公司等级开放的并行制作管线
- **每周指令**：赶进度、抓质量、安抚剧组、压成本、不干预——连赶三周会出事
- 剧本开发、前期筹备、正式拍摄、后期制作四阶段
- 原创IP、正统续集、衍生作品与重启开发
- 三方发行报价；**未来六个月定档**，春节/暑期/国庆/贺岁有商业倍率，也更挤
- 定档后可改一次档（赔付 8%）；院线片跌幅由口碑决定，带首周排片率
- 追加宣传、海外版权、导演剪辑版等发行后运营
- 五类观众资产与六家会真实排片、发行、成长和抢大档期的竞争公司
- **合约与人员流动**：主创有合约期，到期前谈续约（涨薪 / 压价 / 分红），谈崩或放任会流失到对手；对手也会来挖人
- **公司舆情**：0–100 的路人缘，影响作品首发表现与招募签约金，战略页带走势图
- 剧本市场与市场风向；片名组合生成，一局不重样
- 主创招聘、体力、成长与搭档默契
- ★ 明星主创：票房号召力 / 奖项体质 / 话题体质 / 戏路百变四种专属特质
- **62 条抉择事件**：片场四阶段、公司经营、人物、上映期五类，带触发条件与冷却；另有 30 条只进消息栏的行业新闻
- 多幕连锁后果：敏感题材、广告植入、带伤硬拍、长镜头会在数周后回来找你
- 明星塌房危机、挖角对手、限时王牌剧本、票房对赌
- 七阶经营目标与十项成就墙
- 院线、流媒体买断、网络分账三种差异化发行方式
- **公司编年史**（可复制）、**程序化作品海报**、首映夜、作品复盘
- **五种结局**：行业巨头 / 作者厂牌 / 平台代工厂 / 被收购退场 / 还在拍；跨局**名人堂**传承

游戏为纯静态单页应用，支持本机存档和手机浏览器游玩。

## 工程结构

```
index.html        UI 骨架与样式
src/data.js       静态数据表（岗位/类型/受众/设施/对手/开局/档期/目标）
src/events.js     事件库（62 条抉择事件 + 30 条行业新闻）
src/art.js        美术资源清单与降级机制
src/game.js       逻辑与渲染
assets/scene/     场景图与事件氛围图（缺图时自动降级为纯 CSS）
assets/portrait/  人物立绘（缺图时自动降级为色块头像）
docs/             升级规范与出图清单
tests/            核心逻辑测试（node tests/game-core.test.mjs）
```

美术资源是可选的：`assets/` 里没有图，游戏照常运行；丢一张进去就多一处变好看，不需要改代码。出图规范与完整 prompt 见 `docs/出图清单.md`。
